## Reversal KDE Icon Theme
A colorful design icon theme for linux desktops, now even more colorful!

Reversal is an icon pack created by [yeyushengfan258](https://github.com/yeyushengfan258/Reversal-icon-theme)

This Project aims to reimagine the pack with KDE theming integrated.

What does that means for you the end user? No more 50 different color variants just to satisfiy your ever changing desktop themes.

How does this work? Simple, icons that usually change color depending on the color you picked, now change dynamically by pulling your
Accent Color from the KDE Desktop environment.

What that means is, unless you are using KDE, you are not going to get the same results. Infact you'll get no results.
Just the basic KDE blue.

## Install

Usage:  `./install.sh`  **[OPTIONS...]**

|  OPTIONS:           | |
|:--------------------|:-------------|
|-d, --dest           | Specify theme destination directory (Default: $HOME/.local/share/icons)|
|-a, --alternative    | Install alternative icons (redesigned MacOS default icons)|
|-b, --bold           | Install bold panel icons version|
|-r,--remove,-u,--uninstall | Uninstall (remove) icon themes|
|-h, --help           | Show this help|
