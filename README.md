## Reversal KDE Icon Theme
A colorful design icon theme for linux desktops, now even more colorful!

This Icon Pack is designed to work with, and only with the KDE desktop environment.

All folders, and certain apps will change their color based on the accent color
set by the desktop environment. 

If you are not using KDE, the icons will be the default KDE blue accent

## Install

I've crossed out the parameters that aren't needed or not recommended because it will cause issues.
This icon pack is designed to support KDE theming. If you are not using KDE, this icon pack
WILL NOT WORK AS INTENDED.

Usage:  `./install.sh`  **[OPTIONS...]**

|  OPTIONS:           | |
|:--------------------|:-------------|
|-d, --dest           | Specify theme destination directory (Default: $HOME/.local/share/icons)|
|~~-n, --name           | Specify theme name (Default: $THEME_NAME)~~|
|~~-t, --theme          | Specify theme color variant(s) [default/black/blue/brown/cyan/green/grey/grey/lightblue/orange/pink/purple/red/yellow/all] ~~ |
|-a, --alternative    | Install alternative icons (redesigned MacOS default icons)|
|-b, --bold           | Install bold panel icons version|
|-r,--remove,-u,--uninstall | Uninstall (remove) icon themes|
|-h, --help           | Show this help|
